# discordbot workspace

Day la workspace gom nhieu bot Discord vao cung 1 project va chay chung bang 1 lenh.

## Cach dung

1. Dat moi bot trong 1 thu muc rieng o cap goc project.
2. Neu thu muc co `package.json` va co `scripts.start`, launcher se chay `npm start`.
3. Neu thu muc co `index.js`, launcher se chay `node index.js`.
4. Neu thu muc co `main.py` hoac `index.py`, launcher se chay Python file do.
5. Neu ban muon custom command tung bot, copy `bots.config.example.json` thanh `bots.config.json`.
6. Chay tat ca bot bang:

```bash
npm start
```
